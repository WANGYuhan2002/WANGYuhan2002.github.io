## 偏离或补充（请确认）

1. **同一标注带里的标签统一排版**（新增 `L.laneLabels`）。
   - 规则：从右往左排；放得下就写在线的右侧，否则翻到线的左侧，保证互不重叠。
   - 原因：第一次重拍的 `elastic-ps` 里，S 到时靠近 now，`predicted S` 按规格翻到左侧后正好压在 `predicted P` 上，读出来是 “predicte(predicted S”。
   - 现在这种情况下 `predicted P` 也翻到自己线的左侧。
   - 单道记录的 `origin time` 和 `predicted arrival` 共用同一排版。
2. **频谱小图宽度**。
   - 规格写 180 px，但完整标题 `Amplitude spectrum against frequency`（Inter 600 11px）实测 207 px，原来在画布右边被截成 “…frequen”。
   - 现在宽度取 `max(180, 标题宽 + 2)`，约 209 px，记录区相应窄 29 px。
3. **层析崩溃修复**。
   - 现象：一次勘测结束后，改几何或真模型再开新勘测时，残差图越界报错。
   - 原因：上一次勘测的直线反演残差还在，射线却已清空；异常发生在动画帧里，整个模拟随之停住。
   - 修复：
     - 残差随射线一起清空；
     - 残差条数和射线不符时不画；
     - 数据面板绘图加了保护，出错只记一次日志，不再停模拟。
4. **主页记录条**。
   - 14px 标注带始终保留，没有地震时也留着，以免第一次地震时道的位置跳一下。
   - 单道时右侧留 4px 给笔尖圆点，否则圆点会被画布边裁掉一半。
   - 主页没有加 “现在” 竖线，因为 5.2 写了 `drawTrace` “其余不动”。
5. **图注条让波场矮了 33 px**（1440×900 下从 478 变为 445 px），CPU 网格从 400×220 变为 400×205。
   - 影响：依赖网格的数字会变。例如回归顺序里棋盘相关系数从 0.81 变为 0.72。
   - 同一网格（400×220）下，新旧两版层析结果逐位一致，并与你交接里的交叉核对数吻合：
     - 随机模型：残差 −69…+781 ms，均值 +215 ms，96.6 % 晚到，rms 255 → 42 ms，τ = 28 ms，r = 0.965；
     - 棋盘：残差 −196…+108 ms，28.4 % 晚到，63 → 40 ms，r = 0.842。
   - 残差图里画的数，与从拾取独立重算的残差相差不到 3·10⁻⁵ ms。

## 需要你拍板

- **Q1 · 焦斑宽度同屏有两个数。**
  - 现状：标题区和结果卡写 x、z 两向平均的 `0.41 λ`；放大图的横条按规格只量 x 向，写 `FWHM 0.42 λ`。读者会以为其中一个错了。
  - 选项：
    - (a) 横条文字改为 `FWHM along x 0.42 λ`；
    - (b) 横条的长度和文字都用两向平均 0.41 λ；
    - (c) 保持现状。
  - 我倾向 (b)：放大图本来就是给标题区那个数配的图。
- **Q2 · 偏振读数会被前一次地震影响。**
  - 现状：`elastic-ps` 里写的是 `elliptical · retrograde (Rayleigh)`。这本身没错：拍摄时刻最近的 1.2 s 里，正经过进入章节时自动发出的那次浅源的瑞雷波（震源在台站左侧 4.2 km）。
  - 问题：一张讲 P 和 S 的图配上 Rayleigh 读数容易让人困惑；另外顺进 / 逆进按“最后一次震源在台站哪一侧”判断，两次震源分处台站两侧时会判反。
  - 选项：
    - (a) 只在最后一次震源的面波预计到达窗口内写，其余时间只写 `linear` 或 `elliptical`，不写顺 / 逆进；
    - (b) 保持现状。
- **Q3 · 时间反演 `true source` 标签。**
  - 现状：标签在左上 25px。震源靠近圆环时会压到环上的传感器三角（`tr-focus` 里可见），有光晕，仍可读。
